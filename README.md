# college_attendence
Developed a web-based College Management System using Python Flask and MongoDB to manage student records, attendance, marks, and fees. Includes admin login, student registration, CRUD operations, search functionality, and an interactive dashboard.
<br> Technologies: Python, Flask, MongoDB, HTML, CSS, Bootstrap.
Technologies Used: Python, Flask, MongoDB, HTML, CSS, Bootstrap.

Key Features:

Admin authentication and dashboard.

Student registration and profile management.

Attendance and marks management.

Fee management.

Search and update student records.

Student photo upload.

MongoDB database integration.
